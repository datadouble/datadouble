# The integration suite's groups: each runs as the user an engine's copies are
# served as (decision 86), with only the Compose services it needs, split into
# as many CI jobs (shards) as its run time calls for, each taking every Nth
# test (scripts/shard.py). `make test-integration` runs every group whole, one
# after another; `make test-group GROUP=<name>` runs one, and
# `GROUP=<name>/<k>` one of its shards. tests/scripts/test_integration_groups.py
# checks that every test path in pyproject.toml belongs to exactly one group.
#
